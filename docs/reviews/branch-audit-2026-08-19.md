# Branch audit — 2026-08-19

**160 remote branches.** I had been carrying "about 11 stale branches" in my
head all session; that was off by an order of magnitude, which is itself the
finding — the branch picture has been unreliable, and I have been paying for it.
Twice today alone: a PR whose declared base was a lie, and another whose diff
was 90% line-ending noise.

Every branch below was classified by **content**, not by name and not by
ancestry alone. A branch can sit unmerged while its fix shipped by another
route, so "unmerged" never means "work not delivered".

## What I am not doing

Deleting 71 refs is a bulk outward-facing change to a shared repository, so it
is your call, not mine. Nothing here has been deleted.

Recovery, if a deletion is ever regretted: for the 71, the commits are on `main`
and the ref can be recreated from any SHA. For the rest, a deleted branch's
commits survive in the remote's reflog for a limited window and in any local
clone that still has the ref — so the recoverable window is real but not
indefinite.
